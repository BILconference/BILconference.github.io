Hosted a BIL, or found one missing from the archive? This site is a plain
[GitHub repository](https://github.com/BILconference/BILconference.github.io) —
adding an event is adding a file.

1. Create a Markdown file in `_events/` (each folder's README documents the
   fields — title, dates, venue, country, organizers, and so on).
2. Add speakers and talks the same way in `_speakers/` and `_talks/`,
   linking them to the event by its slug.
3. Open a pull request, or [open an issue](https://github.com/BILconference/BILconference.github.io/issues)
   with the details and links if Git isn't your thing.

Thinking about running a new BIL instead? Start with
[Host a BIL](/host-a-bil/).
