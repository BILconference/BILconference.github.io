Author of the book "Getting started with React VR" The Immersive Web is now supported in all major browsers. If you know HTML, VR is now as easy as <box>. Instead of having to learn game engines, etc. if you know HTML and Javascript, you can build real VR experiences; on any hardware. John will also discuss how VR is leveling off, and "Video killed the VR Star" (with apologies to the Buggles); the Fermi paradox and VR, and how VR doesn't have to look real to seem real.
