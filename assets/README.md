# Assets

- `css/main.css` — the design, from the original bil-theme: sky blue
  `#2ea3f2` on white, navy `#084f7f`, slate `#323944`, Hind + Open Sans.
- `css/flags.css` — sprite offsets for the country flags on event pages.
- `js/yt-embed.js` — progressive enhancement that turns standalone YouTube
  links in page bodies into click-to-play players.
- `img/` — original theme graphics: the neuron hero banner
  (`banner-brain.jpg`), the dotted world map (`world_map.png`), the flag
  sprite (`flags32.png`), the speaker placeholder (`blank-person.png`),
  and the Creative Commons footer badge.
