# Data

`bil_words.yml` — the BIL backronym word bank: fun/edgy words under `b:`,
`i:`, and `l:` keys, for expanding what BIL "stands for" (it doesn't —
that's the joke). `b`/`i` are modifiers and `l` is mostly nouns, so any
random combination reads well. Access in Liquid as
`site.data.bil_words.b` etc. Seeded from expansions preserved in the
archive; add words freely, keep them in the site's irreverent register.
