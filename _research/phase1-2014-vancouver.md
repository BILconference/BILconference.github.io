# Phase 1 research: BIL 2014 Vancouver (event slug `bil-2014`)

Researched 2026-08-23. Scope: the main BIL 2014 event, Vancouver BC, March 22-23 2014, at Five-Sixty (560 Seymour St) — distinct from BIL:SF 2014 (`bil-sf-2014`, San Francisco, March 1-2 2014), which already has 17 talks in `_talks/`.
