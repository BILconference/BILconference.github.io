# Line-up recovery research files

Evidence trail for the August 2026 line-up recovery (PRs #23–#26): source
inventories, per-year dry-run tables with confidence grades, verbatim period
text with snapshot URLs, the video-matching log, and the per-event
Tunisia/international findings — including entries deliberately *excluded*
(signup-only names, unverifiable identities) and leads for future passes
(period photo URLs, unlabeled talk footage, Flickr tags).

This directory is not a Jekyll collection and is never published; it exists so
every claim on the site can be traced back to its period source. Research was
AI-assisted (Claude); quoted period text is verbatim from the cited captures.
